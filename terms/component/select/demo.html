表单两兄弟 · Select 演示

演示词条 C-15。并排两个 <select> 走同一份表单语义 （label 关联、值随提交走、键盘原生）与同一份换皮底座：左列是最小成本重绘 （appearance:none + 自绘箭头 + accent-color）， 右列验证同一底座的边界（optgroup / disabled / 长文本）。 本页交互 JS 为 0 行——选中回显用 :has(option:checked)。 base-select 定制弹层为何不进 demo：见词条正文「两条轨道」一节（Chromium 槽位行为未收敛）。

引擎轨道：

左列 · 原生派

appearance:none 重绘触发器 + 自绘箭头 + accent-color 给弹层高亮上色。弹层本体（桌面浮层 / iOS 滚轮 / Android 全屏）仍是 UA 黑盒——这是它的头号坑，也是它的零维护红利。 注意 optgroup 分组与 disabled 选项。

右列 · 同一底座的变体

同一份换皮底座换内容与尺寸参数，验证「重绘的边界」： optgroup 分组在自绘箭头下是否仍可读、disabled 项置灰、 长选项文本不顶破箭头位。base-select 定制弹层的叙事见词条正文—— Chromium 槽位行为未收敛前，demo 只交付生产可放心粘贴的形态。
