下拉菜单 Dropdown Menu

演示词条 C-14。点「更多操作」→ 菜单浮起。开关、点外关闭、Esc 全是 0 行 JS （popover="auto" + popovertarget 白送）；位置在支持的浏览器里由 anchor() + position-try-fallbacks: flip-block 算， 不支持时退化成 JS 读 getBoundingClientRect() 摆放——同一观感，两条路。 往下滚到视口底缘再开，能看到它自动翻到按钮上方。 菜单项是动作（点了立即执行并回显），这是它和 Select（选值）的分界。 键盘：↓↑ 移动、Home/End 首尾、Enter 执行、Esc 退出。
